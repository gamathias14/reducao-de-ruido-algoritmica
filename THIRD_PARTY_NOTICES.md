# Avisos de terceiros

Este repositório contém adaptadores, scripts de build e referências para
projetos externos. As fontes, modelos, datasets e binários desses projetos não
são redistribuídos aqui.

| Componente | Origem | Licença registrada | Política neste repositório |
|---|---|---|---|
| RNNoise | Xiph.Org, tag `v0.2` | BSD-3-Clause | código/modelo obtidos da fonte oficial; somente adaptadores próprios e hashes são publicados |
| WebRTC Audio Processing | repositório oficial WebRTC | BSD-3-Clause | binário e checkout externo não publicados |
| DeepFilterNet3 | projeto DeepFilterNet, tag `v0.5.6` | MIT ou Apache-2.0 | wheel, modelo e biblioteca nativa não publicados |
| DEMAND | base Diverse Environments Multi-channel Acoustic Noise Database | CC BY-SA 3.0 | ZIPs e WAVs brutos não publicados |
| SYSVAD | Microsoft Windows Driver Samples | termos do repositório oficial da Microsoft | fontes, pacote, certificado e binários externos não copiados |
| FSDD | Free Spoken Digit Dataset | consultar o repositório oficial | downloads locais não são republicados como parte do fechamento |

Os usuários devem obter cada dependência em sua fonte oficial e respeitar sua
licença, termos e requisitos de atribuição.
